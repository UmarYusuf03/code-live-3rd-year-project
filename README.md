# CodeLive

Real-time collaborative coding and execution platform tailored for live coding sessions, technical interviews, and classrooms.

## Tech Stack
- ASP.NET Core 9 (SignalR, WebSockets)
- Angular 19 (Signals, Standalone Components)
- Monaco Editor (VS Code core)
- Yjs CRDT for Conflict-free Replication
- Judge0 CE Sandbox Engine
